

# Taxi Game Simulation

### *Simulation of taxi driver behavior and dynamic pricing using game theory*

*(Моделирование поведения водителей такси и динамического ценообразования с использованием теории игр)*

---

##  Overview

Этот проект моделирует работу сервиса такси как **некооперативную игру между водителями**, где каждый агент стремится максимизировать собственный доход.
Симуляция учитывает:

* изменяющийся спрос в разных зонах города,
* динамическое ценообразование (surge pricing),
* стратегии водителей по выбору зон и заказов,
* перераспределение агентов в пространстве.

Платформа регулирует цены, чтобы балансировать спрос и предложение между зонами и стимулировать водителей перемещаться в дефицитные районы.

---

##  Goals

* Смоделировать дисбаланс спроса и предложения в городских зонах.
* Реализовать алгоритмы динамического ценообразования (*surge pricing*).
* Создать поведение агентов-водителей: выбор зоны, принятие/отказ от заказов.
* Исследовать, возникает ли **равновесие Нэша** при разных настройках системы.
* Построить визуализации и собрать аналитическую статистику симуляции.

---

##  Features

* Несколько городских зон с различными уровнями спроса.
* Генерация заказов с использованием вероятностной модели (Пуассон).
* Рациональное поведение водителей: выбор заказов, смена зоны, оценка прибыли.
* Динамическое изменение тарифов в зависимости от спроса и доступных водителей.
* Подробная аналитика: доходы, выполненные/отменённые заказы, загрузка зон.
* Визуализация работы всей системы и поведения агентов.

##  How It Works

* На каждом шаге симуляции генерируются новые заказы в каждой зоне.
* Водители принимают решения:

  * взять заказ,
  * отказать,
  * переместиться в более выгодную зону.
* Платформа пересчитывает динамический множитель цены для каждой зоны.
* С течением времени система стремится достичь **стабильного распределения водителей** — аналога равновесия Нэша.
